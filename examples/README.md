# Example packs

Each pack is a self-contained set of artifacts under `examples/<pack>/<KIND>/`, plus the code and
records they cite. The kit itself is domain-neutral: packs are where a domain appears.

| Pack | Domain | ID system | What it exercises |
|------|--------|-----------|-------------------|
| `qi/` | quantum information theory | `qi` | certificate layer (EJM Farkas certificate, SRB independent checks), theorem layer (PGR bound information claim graph), verification intake (EJM plan), discovery layer (CHSH deterministic bounds: proved / refuted / supported) |
| `euler-polynomial/` | number theory | `nt` | discovery layer only, no physics: Euler's n² + n + 41 — the famous pattern refuted at n = 40, its restriction proved, a deeper statement supported |

Gate a pack with `python3 scripts/graph_gate.py examples/<pack>`; CI does this for every pack.
Script-generated artifacts (PROOF-ATTEMPT, CHECK-RUN) are regenerated by the scripts, never edited.
